Política de Privacidade

App "Hermes", assistente pessoal de Leonardo Mattana · Atualizada em 11/10/2026

O app "Hermes" é um assistente de uso exclusivamente pessoal. Ele roda no computador do próprio titular e é usado apenas pelas contas Google dele. Não é oferecido ao público.

Dados acessados

Com autorização explícita via OAuth do Google, o app pode ler, organizar (marcadores), redigir e enviar e-mails do Gmail e ler e criar eventos do Google Agenda das contas do titular.

Uso dos dados

  • Os dados são processados localmente para gerar resumos, organizar a caixa de entrada e preparar o planejamento diário do titular.
  • Trechos podem ser enviados a um provedor de modelo de linguagem (Anthropic) somente para gerar esses resumos, sob os termos desse provedor.
  • Nenhum dado é vendido, compartilhado com terceiros para publicidade ou usado para treinar modelos pelo app.
  • O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento e exclusão

Os tokens de acesso ficam salvos apenas no computador do titular. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
